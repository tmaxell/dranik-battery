# dranik-battery

Открытая, легковесная альтернатива [AlDente](https://apphousekitchen.com/) для MacBook на Apple Silicon.

Цель первой версии — сделать ровно две вещи и сделать их безопасно:

1. **Ограничение заряда** — не давать батарее заряжаться выше заданного порога (по умолчанию 80 %).
2. **Контроль питания** — наблюдать за состоянием батареи и адаптера: процент, ток, напряжение,
   мощность на входе, температура, износ, число циклов.

Всё остальное (принудительный разряд, калибровка, sailing mode, GUI, расписания) — за пределами
первой итерации.

## Статус

🚧 **Только чтение.** Реализован слой доступа к SMC, снимок состояния батареи и CLI `dranik`.

**В SMC ничего не записывается** — метода записи в API нет вовсе. Значит эта сборка физически
не может изменить то, как машина заряжается. Ограничение заряда появится отдельным изменением,
вместе с механизмами защиты от отказов, которые обязаны его окружать.

## Целевая платформа

| | |
|---|---|
| Железо | MacBook Pro 13″ M1 (`MacBookPro17,1`), 16 GB / 512 GB |
| macOS | 14.8.7 (23J520) |
| Тулчейн | Swift 6.0.3 из Command Line Tools (Xcode **не** требуется) |

Поддержка Intel-маков в планы не входит.

## Сборка и запуск

```bash
make build
make test
make status
```

```
$ dranik status
Battery
  Charge                  100 %
  State                   full
  Health                  92.4 % (4716 / 5103 mAh)
  Cycles                  170
  Temperature             30.4 °C
  ...

Charge control
  Charge gate             CHTE (single key)
  Hardware 80 % limit     no
  Adapter control keys    CH0J, CHIE
  CHTE reads              0
```

Команды:

| Команда | Что делает |
|---|---|
| `dranik status [--json]` | Состояние батареи, возможности управления зарядкой, потребление |
| `dranik smc <KEY>...` | Чтение конкретных SMC-ключей, например `dranik smc CHTE B0AV` |
| `dranik smc --dump` | Полный перебор всех SMC-ключей в TSV |
| `dranik help` | Справка |

Root не нужен: чтение SMC работает от обычного пользователя. Запись требует root — но её здесь нет.

## Структура

```
Sources/
  CDranikSMC/     Раскладка SMCParamStruct — в C, чтобы её гарантировал компилятор
  DranikSMC/      Доступ к AppleSMC: зондирование ключей, чтение, определение возможностей
  DranikPower/    Публичный IOKit: снимок AppleSmartBattery
  dranik/         CLI
Tests/
  DranikSelfTest/ Набор тестов
tools/
  smcprobe.c      Точечная read-only проба — эталонная реализация
  smcdump.c       Полный перебор ключей — эталонная реализация
```

### Почему тесты — это исполняемый файл, а не `swift test`

XCTest поставляется вместе с Xcode, а swift-testing требует тулчейна с модулем `Testing`.
На целевой машине установлены только Command Line Tools, поэтому ни один из них не
импортируется и `swift test` работать не может. Вместо того чтобы делать Xcode обязательным
или тянуть сетевую зависимость, набор тестов — обычный исполняемый файл: `make test`,
ненулевой код возврата при провале.

Утверждения названы так же, как в XCTest, чтобы переход на него был механическим,
если Xcode когда-нибудь появится.
